ncrf.NCRFExecutionContext¶

class ncrf.NCRFExecutionContext(timestamp=None, duration=None, eelbrain_version=None, python_version=None, numpy_version=None, platform=None, os_version=None, machine=None, compiler=None, compile_flags=None, n_workers=None, ncrf_version=None)¶

Context in which an NCRF was fitted.

Stored as NCRFFit.execution_context. Extends Eelbrain’s ExecutionContext, which records the time, duration, package versions and platform of a fit, with the ncrf version.

Parameters:

ncrf_version (str | None) – ncrf version used for the fit.
