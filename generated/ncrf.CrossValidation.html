ncrf.CrossValidation¶

class ncrf.CrossValidation(n_splits=3, n_workers=None)¶

Configuration for selecting among solver candidates.

Parameters:

  • n_splits (int) – Number of cross-validation folds.

  • n_workers (int | None) – Number of worker processes, or None to derive it from Eelbrain’s n_workers setting (see eelbrain.configure()). Set to 0 to run without multiprocessing, for debugging.
