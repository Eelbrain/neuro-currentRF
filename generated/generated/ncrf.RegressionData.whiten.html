ncrf.RegressionData.whiten¶

RegressionData.whiten(forward)¶

Return a dataset whose responses are whitened with forward.

Parameters:

forward – Forward model for exactly this dataset’s sensors, in the same order. Its whitening filter is applied to the responses, and it is recorded as forward. If the dataset is already whitened with an equivalent forward model (same lead field and noise covariance), it is returned unchanged.

Raises:

ValueError – If forward has different sensors than the dataset, or if the dataset is already whitened with a different forward model: the forward model whitened data carries is the one it is fit with, and whitening twice is not equivalent to whitening once with the second filter (W₂ @ W₁ @ meg ≠ W₂ @ meg).
