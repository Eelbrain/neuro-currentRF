ncrf.NCRFExecutionContext.collect¶

classmethod NCRFExecutionContext.collect(t_start, t_done, n_workers=None, compile_flags=None, compiler=None, **fields)¶

Describe a fit that was run in the current process

Parameters:

  • t_start – Time at which the fit started (from time.time()).

  • t_done – Time at which the fit finished.

  • n_workers – Number of parallel workers configured for the fit.

  • compile_flags – Compiler flags of the compiled extension used for the fit.

  • compiler – Compiler with which the compiled extension was built.

  • **fields – Values for additional fields of a subclass.
