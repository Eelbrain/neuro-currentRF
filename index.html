Neuro-currentRF¶

Neuro Current Response Functions (NCRFs) are cortical temporal response functions (TRFs) directly estimated from continuous M/EEG data. The NCRF framework combines the temporal response model with a distributed forward model and estimates the source-space filters with a Bayesian optimization algorithm [Das et al., 2020].
